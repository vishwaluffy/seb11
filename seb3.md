##Write a python program for bitwise shift operators on the user given integers

#Aim
```
To write a python program to find the maximum of two integer numbers using conditional expression(Ternary).
```
#algorithm.
```
1. Start.
2. Input two integer numbers: `a` and `b`.
3. Compute maximum using ternary: `max_val = a if a > b else b`.
4. Output `max_val`
```
##program
```
num1=int(input())
num2=int(input())

if(num1>num2):
    print(f"The maximum of {num1} and {num2} is {num1}")
else:
    print(f"The maximum of {num1} and {num2} is {num2}")

```
