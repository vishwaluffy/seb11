##Write a python program for bitwise shift operators on the user given integers

#Aim
```
To Write a python program for bitwise shift operators on the user given integers
```
#algorithm.
```
1. Start.
2. Input an integer number num and number of positions to shift shift.
3. Compute left shift: `left_shift = num << shift`. 
4. Compute right shift: `right_shift = num >> shift`.
5.Output `left_shift` and `right_shift`.
6. End
```
##program
```
num=int(input())
num1=int(input())

x=num>>num1
y=num<<num1
print(x)
print(y)
```
